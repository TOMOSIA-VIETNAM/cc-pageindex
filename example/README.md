# Sample document

This directory holds the book *SHOKUNIN IT – Cách người TOMOSIA làm việc* by Lưu Tuấn Anh
(TOMOSIA): the PDF, and the index `pi.py` built from it (`pageindex/`, whose `pages.json`
carries the book's text), plus the viewer page generated from that index
(`preview-node-index.html`). The landing page in `webapp/` embeds that viewer page.

The book and everything derived from it here are **not** covered by the repository's MIT
license. They belong to their author and are included with permission, as a sample to try
the skill on. Do not redistribute them outside this repository.
